# Vanguard Digital Studio — Creative Freelancer Platform

A modern, high-performance creative digital studio & freelancing platform engineered with **Next.js App Router (React 19)**, **TypeScript**, **Tailwind CSS**, **Motion for React**, **Prisma ORM**, and **PostgreSQL (Render)**.

---

## 🌟 Architecture & Completed Phases

### Phase 1 — Creative Digital Studio Portfolio
- **Aesthetic**: Premium dark charcoal (`#07080b`) aesthetic with electric blue (`#00f0ff`) and violet accents.
- **Interactions & Micro-Animations**: Smooth scroll reveals, card hover states, accessible reduced-motion support (`prefers-reduced-motion`).
- **Complete Page Suite**:
  1. `Home` (`/`): Dynamic hero with 3 CTAs (*View Projects*, *Start a Project*, *Book a Call*), featured project showcases, development workflow, tech stack, sample testimonials, and discovery booking modal.
  2. `About` (`/about`): Engineering philosophy, background story, design & code principles, career milestones timeline.
  3. `Services` (`/services`): Detailed breakdown of 6 core services (Business Websites, Dynamic Web Apps, CRM Panels, E-Commerce, API Integration, Redesigns) with deliverables and timelines.
  4. `Portfolio / Projects` (`/projects`): Instant client-side search, category filter pills, demo links, and *Build Something Similar* CTA.
  5. `Individual Case Studies` (`/projects/[slug]`): In-depth architectural case studies with challenges, solutions, metrics, and technology badges.
  6. `Contact` (`/contact`): Inquiry form and 30-minute discovery call booking scheduler.
  7. `FAQ` (`/faq`): Categorized interactive accordions.
  8. `Privacy & Terms` (`/privacy`, `/terms`): Clean legal placeholders.

### Phase 2 — Backend & Database Foundation
- **Database**: PostgreSQL hosted on Render, modeled via Prisma ORM.
- **Schema**: Users, Portfolio Projects, Services, Leads, Project Requests, Proposals, Milestones, Bookings, Messages, Invoices, Payments, Notifications.
- **Security & Hygiene**: Sanitizing server logger masking credentials and database URIs; non-sensitive `/api/health` monitoring route.
- **Seed Script**: Demo data with explicit sample tags (`npm run db:seed`).

### Phase 3 — Authentication & Role-Based Access Control (RBAC)
- **Role Hierarchy**: Two distinct roles: `CLIENT` and `ADMIN`.
- **Server Sessions**: Cryptographically secure token sessions with database persistence and auto-expiry.
- **Bcrypt Security**: Passwords hashed with 12 salt rounds; constant-time hash simulation on non-existent accounts to eliminate timing enumeration attacks.
- **Route Protection**: Edge middleware verification + strict database-backed Server Component and Route Handler verification (`requireAuth`, `requireAdmin`, `canAccessResource`).
- **Admin Bootstrap**: Public admin registration is strictly disabled; bootstrap admin securely via `npm run auth:bootstrap-admin`.

### Phase 4 — Project Booking & Lead CRM
- **Client Project Builder** (`/get-started`): 8-step multi-step interactive project brief configurator with dynamic feature options per project type (business website, dynamic application, CRM panel, e-commerce, dashboard, custom).
- **Idempotency & Duplicate Prevention**: Server-side idempotency lock to block rapid duplicate submissions.
- **Unique Reference Numbers**: Autogenerated `PRJ-YYYY-XXXXXX` project references and `QUO-YYYY-XXXXXX` quotation numbers.
- **Admin Lead CRM** (`/admin/crm`): Filterable, searchable, and paginated lead CRM with stage management (`NEW`, `CONTACTED`, `QUALIFIED`, `PROPOSAL_SENT`, `WON`, `LOST`), internal notes, follow-up scheduling, and 1-click lead-to-project conversion.
- **Quotation Generator**: Create itemized quotations with line items, scope, pricing, validity, timeline, and audit logs.

### Phase 5 — Client Portal & Project Management
- **Project Lifecycle Pipeline**:
  $$\text{ENQUIRY} \longrightarrow \text{DISCUSSION} \longrightarrow \text{QUOTATION} \longrightarrow \text{APPROVED} \longrightarrow \text{DEVELOPMENT} \longrightarrow \text{REVIEW} \longrightarrow \text{DELIVERED}$$
- **Client Workspace** (`/portal` & `/portal/projects/[id]`):
  - Dashboard displaying client's active project requests and proposals.
  - Interactive project detail view with visual pipeline tracker.
  - **Milestone Roadmap**: Checkpoint timeline with progress percentage, deadlines, and delivery statuses.
  - **Protected Document Downloads**: Dedicated `/api/portal/documents/[id]/download` route enforcing cross-client isolation, private cache headers, and streaming delivery.
  - **Proposal Review & Acceptance**: Interactive review modal; client acceptance automatically transitions project stage to `APPROVED` and writes an audit log.
  - **Scope Change Requests**: Modal form for clients to submit change requests; admin reviews technical feasibility, additional cost, and timeline adjustments.
  - **Discussion Thread**: Authenticated communication log between client and studio team.
  - **Handover Section**: Live staging/production URLs, repository links, credentials, and hosting instructions.
### Phase 6 — Real-Time Chat, Call Booking & Notifications
- **Standalone Socket.IO Service** (`realtime/server.ts`):
  - High-performance WebSocket microservice running on port `3001` sharing the same PostgreSQL database and Prisma client.
  - Authenticates socket handshakes strictly from database sessions — never trusting client-supplied user IDs.
  - Strict room authorization: clients can only join rooms for projects they own (`canAccessResource`); administrators can join any.
  - Real-time events: `join:project`, `message:send`, `message:read` (read receipts), `typing:start`/`stop` (typing indicators).
  - Built-in rate limiting per socket (max 15 messages per 10s).
- **Resilient Client Chat Box** (`RealtimeChatBox.tsx`):
  - Live status indicator: `Connected (Live Real-Time)` / `Reconnecting...` / `HTTP Sync (Offline Fallback)`.
  - Graceful fallback: when the WebSocket service is offline, the client automatically falls back to secure HTTP REST persistence without breaking any website functionality.
  - Supports protected file attachments (PDFs, images, archives up to 15MB) uploaded through `/api/portal/chat/attachments`.
  - Real-time read receipts (`✓ Sent` and `✓✓ Read`) with recipient read timestamps.
- **Enhanced Call Booking & Slot Management** (`BookCallModal.tsx`):
  - Slot discovery endpoint (`/api/bookings/slots`) returning studio business hour slots (30 mins).
  - Real-time double-booking conflict prevention: rejects overlapping slots with HTTP 409 Conflict.
  - Automatic browser timezone detection (`Intl.DateTimeFormat`) while storing timestamps strictly as UTC in PostgreSQL.
  - Automatic Google Calendar URL generator and virtual Google Meet link provider.
  - Self-service reschedule and cancellation endpoints (`/api/bookings/[id]/reschedule`, `/api/bookings/[id]/status`).
- **In-App Notification Center** (`NotificationCenter.tsx`):
  - Unread notification count badge in header navbar with pulsating indicator.
  - Dropdown view categorized by alert type (`INFO`, `SUCCESS`, `WARNING`, `ACTION_REQUIRED`).
  - Automated triggers for new chat messages, appointment confirmations, project stage changes, and quotation updates.
  - "Mark as Read" and "Mark All as Read" actions.

### Phase 7 — Invoices & Razorpay Payment Integration
- **Auditable Invoicing**:
  - Autogenerated unique reference numbers formatted as `INV-YYYY-XXXXXX`.
  - 1-click invoice generation from approved Quotations, project Milestones, or Custom deliverables.
  - Itemized line items, configurable tax rate (e.g. 18% GST/VAT), calculated subtotals, and due dates.
  - Comprehensive status lifecycle: `DRAFT`, `ISSUED`, `PARTIALLY_PAID`, `PAID`, `OVERDUE`, and `CANCELLED`.
  - Complete `InvoiceAuditLog` trail capturing state changes, actors, and notes.
- **Printable & PDF Invoice Engine** (`/portal/invoices/[id]`):
  - Clean studio letterhead with client billing info, itemized table, and tax calculations.
  - Native print stylesheet (`@media print`) for high-contrast physical printing or PDF downloads.
- **Razorpay Server-Side Integration**:
  - Server-side order creation (`/api/payments/razorpay/order`) — amount is strictly derived from the database invoice balance and never trusted from the client.
  - Cryptographic HMAC-SHA256 signature verification (`/api/payments/razorpay/verify`) using constant-time comparison to prevent timing attacks.
  - Razorpay Webhook endpoint (`/api/webhooks/razorpay`) with raw-body signature verification.
  - Webhook Idempotency: Duplicate event delivery protection via `ProcessedWebhookEvent`.
  - Transaction Reconciliation: Handles partial payments, full settlements, payment failures, and refund reversals.
  - Interactive client payment modal with fallback sandbox mode for offline testing.

### Phase 8 — Production Readiness & Render Deployment
- **Render Infrastructure as Code (`render.yaml`)**:
  - Single-command automated Blueprint provisioning both the Next.js Web Service and Managed PostgreSQL in the same region (`oregon`).
  - Private network VPC connection using Render internal database URLs for zero latency and no egress fees.
- **Safe Deployment Pipeline**:
  - Pinned Node.js runtime (`.node-version` 20.18.0) and `package.json` engine requirements.
  - Safe automated migrations via `npx prisma migrate deploy` in the build command before code deployment.
  - Port binding compatibility with hosting environments (`PORT` environment variable).
- **Hardened Security & Headers (`next.config.mjs`)**:
  - `X-Content-Type-Options: nosniff`
  - `X-Frame-Options: SAMEORIGIN`
  - `X-XSS-Protection: 1; mode=block`
  - `Referrer-Policy: strict-origin-when-cross-origin`
  - `Permissions-Policy: camera=(), microphone=(), geolocation=()`
  - `Strict-Transport-Security: max-age=63072000; includeSubDomains; preload`
  - Content Security Policy (CSP) allowing Razorpay Checkout and external CDNs.
- **Disaster Recovery & Rollback**:
  - Documented automated Render daily backups and manual `pg_dump` / `pg_restore` procedures.
  - 1-click deployment rollback via Render Dashboard and database snapshot restore.

## 🚀 Quick Start (Local Development)

```bash
# 1. Install dependencies
npm install

# 2. Configure environment
cp .env.example .env

# 3. Generate Prisma client & apply migrations
npx prisma generate
npx prisma migrate dev

# 4. Bootstrap Administrator account
npm run auth:bootstrap-admin

# 5. (Optional) Populate database with sample data
npm run db:seed

# 6. Start development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000).
